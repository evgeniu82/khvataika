# Онлайн-часть — план подключения

Локальная версия игры не притворяется глобальной онлайн-системой. Для настоящего общего рейтинга, аккаунтов и облачной синхронизации нужен сервер.

Рекомендуемые сущности API:

- `POST /v1/auth/guest` — гостевой аккаунт.
- `GET /v1/profile` / `PUT /v1/profile` — профиль и прогресс.
- `GET /v1/leaderboard?season=...` — общий рейтинг.
- `GET /v1/events` — глобальные события.
- `GET /v1/tournaments` — турниры.
- `POST /v1/sync` — безопасная синхронизация прогресса.

Минимальная серверная база: PostgreSQL + HTTPS API + авторизация по токену. Клиент уже разделяет локальные данные так, чтобы эти системы можно было подключить без изменения цветовой схемы и основного интерфейса.
