# Онлайн-подключение v1.12.3

Сервер игры: http://135.106.209.40:8080

При запуске игра регистрирует игрока через `/api/player/register`, получает конфигурацию через `/api/config`, синхронизирует прогресс через `/api/player/sync`, рейтинг через `/api/rating`, а также использует API реферальных кодов и промокодов.

Для Android в экспортном пресете уже включено разрешение INTERNET.
