# Хватайка 1.18.40 — полный аудит достижений

## Критическая причина исправления
В старых сохранениях массив `owned_claws` мог быть короче актуального списка из 10 клешней. Старая загрузка принимала массив только если его длина была ровно 10. Поэтому уже купленные клешни из старого сохранения могли игнорироваться и заменяться значениями по умолчанию. Это приводило к ситуации вроде `1 / 3`, хотя игрок уже открыл 4 клешни.

Также выполненное достижение за баланс могло отображаться как `129 / 500` после траты денег, хотя оно уже было выполнено.

## Исправления
- Миграция массивов владения теперь сохраняет все существующие значения даже при старом размере массива и дополняет массив до актуального размера.
- То же исправлено для скинов клешни, игрушек и аппарата.
- Выбранная клешня/скин дополнительно считается принадлежащим игроку при аудите сохранения.
- При запуске выполняется полный аудит источников достижений.
- После полной инициализации выполняется повторная проверка всех достижений.
- Во время игры `check_achievements()` продолжает выполняться автоматически каждые 0.5 секунды, поэтому уже достигнутое условие подхватывается без необходимости заходить в отдельное меню.
- Баланс для достижений `500 / 1000 / 5000 ₽` считается по максимальному достигнутому балансу, а не по текущему балансу после последующих покупок.
- Инвентарь игрушек ретроактивно восстанавливает общий счётчик игрушек и счётчики редкостей.
- Завершённые коллекции ретроактивно восстанавливаются из фактического инвентаря.
- Выполненные достижения в интерфейсе всегда показывают `цель / цель`, а не уменьшенный текущий показатель после последующих трат.
- Проверены все 130 достижений: 39 базовых + 46 прогрессивных + 45 дополнительных.
- Для всех 28 типов условий существует обработчик в `achievement_value()`.

## Важно
Награда выдаётся только один раз: после добавления ID в `unlocked_achievements` повторная проверка не выдаёт награду повторно.
