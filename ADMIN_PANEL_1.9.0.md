# Админ-панель v1.9.0

В проект добавлена папка `server/`. Это отдельный Node.js сервер, который хранит серверную конфигурацию и предоставляет веб-админку.

## Быстрый запуск
1. Установить Node.js 18+.
2. В терминале открыть папку `server`.
3. Задать `ADMIN_PASSWORD` и запустить `node server.js`.
4. Открыть адрес сервера в браузере.
5. В игре: **Настройки → Онлайн-сервер** → указать тот же URL API.

Для публичного использования нужен HTTPS и сильный пароль. Не оставляйте пароль `change-me-now`.

## Управляемые разделы
- Промокоды: код, награда, лимит, срок, активность.
- Новости: обновления, события и промокоды.
- События: название, описание, срок, бонус, множитель награды.
- Настройки игры: техработы, глобальное объявление, множитель наград, ежедневные/еженедельные награды, бонус возвращения, время уведомлений.
- Игроки: рейтинг, просмотр активности, блокировка/разблокировка, серверное изменение баланса.
- Журнал действий администратора.

## Серверная проверка промокодов
При заданном URL сервера клиент отправляет код на `/api/promo/redeem`. Сервер проверяет срок, лимит, активность и факт предыдущего использования конкретным игроком. Локальные коды используются только когда URL сервера не задан.
