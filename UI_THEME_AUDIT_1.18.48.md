# KHVATAIKA 1.18.48 — UI THEME DEEP FIX

## Причина
В 1.18.44–1.18.47 часть элементов уже имела коричневые overrides, но Android/Godot всё ещё мог показывать стандартные серые `ConfirmationDialog`/`AcceptDialog` и стандартные системные стили динамических контролов. Поэтому визуально изменения могли быть незаметны.

## Исправление
1. Глобальная коричневая Theme назначается корню окна игры.
2. Стандартизированы Button, OptionButton, CheckButton, PopupMenu, LineEdit, HSlider, VScrollBar и HScrollBar.
3. Переключатели используют коричневые SVG-иконки on/off.
4. Стандартные ConfirmationDialog/AcceptDialog больше не используются для игровых подтверждений. Вместо них создаётся обычный компактный PanelContainer внутри игрового `menu_layer`, поэтому системный серый фон Android/Godot не может появиться.
5. Исправлены окна:
   - Сброс прогресса;
   - Восстановление настроек;
   - Технические работы;
   - Подтверждение покупок;
   - Подтверждение открытия сундуков.
6. Выпадающие меню OptionButton получают коричневый PopupMenu.
7. Все изменения только визуальные; достижения и игровая логика в этой версии не менялись.

## Проверка
По исходнику выполнен поиск стандартных `ConfirmationDialog`/`AcceptDialog` в игровых функциях: они удалены из пользовательских модальных сценариев. Остальные стандартные контролы получают глобальную тему и точечные overrides.

Игровые цвета игрушек, редкостей, скинов и 3D-контента не перекрашиваются.
