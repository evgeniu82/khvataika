# Фоновые уведомления — Хватайка 1.8.0

В версии 1.8.0 система уведомлений расширена: расписания работают через Android AlarmManager + BroadcastReceiver и могут срабатывать при полностью закрытой игре.

## Типы уведомлений

- Ежедневная награда — 12:00.
- Серия входов — 20:00.
- Сундук — напоминание при наличии ключей.
- Событие — напоминание примерно за 3 часа до окончания.
- Мастерская — при завершении фоновой инженерной работы.
- Бонус за возвращение — при доступности награды.

## Один раз в Godot

1. Открой `project.godot`.
2. Установи Android Build Template: **Проект → Установить шаблон сборки Android**.
3. В **Проект → Настройки → Плагины** включи `Хватайка Background Notifications`.
4. В Android Export preset оставь **Gradle Build → Use Gradle Build = true**.
5. На Android 13+ разреши уведомления при первом запуске.

Плагин автоматически добавляет Java BroadcastReceiver и разрешение `RECEIVE_BOOT_COMPLETED`.

## Важно

Android может немного сдвигать время `setAndAllowWhileIdle` ради экономии батареи. Это нормально для обычных игровых напоминаний.
