# Онлайн-подключение v1.12.4

Сервер игры: http://135.106.209.40:8080

При запуске игра регистрирует игрока через `/api/player/register`, получает конфигурацию через `/api/config`, синхронизирует прогресс через `/api/player/sync`, рейтинг через `/api/rating`, а также использует API реферальных кодов и промокодов.

Для Android в экспортном пресете уже включено разрешение INTERNET.


## Серверная модель v1.12.4
Игровое состояние игрока, рейтинг, сундуки, мастерская, сезон, промокоды, рефералы, новости, события и серверные настройки синхронизируются с Selectel.
Уведомления создаются сервером и доставляются приложению через серверную очередь; Android receiver дополнительно опрашивает очередь в фоне.
