# Сервер «Хватайка» + админ-панель

## Запуск
Требуется Node.js 18+.

```bash
cd server
ADMIN_PASSWORD="СИЛЬНЫЙ_ПАРОЛЬ" node server.js
```

После запуска:
- админ-панель: `http://localhost:8080/`
- проверка: `http://localhost:8080/health`

Для телефона сервер должен быть доступен по HTTPS. Адрес сервера уже встроен в игру и обычному игроку показывать его не нужно.

## Что умеет админ-панель
- промокоды: награда, лимит активаций, срок, включение/выключение;
- новости: публикация обновлений, событий и промокодов;
- события: активность, срок, бонус, множитель награды;
- экономика: множители и размеры наград;
- режим техработ и глобальное объявление;
- время фоновых уведомлений;
- список игроков, блокировка/разблокировка, изменение баланса;
- журнал действий администратора;
- глобальный рейтинг.

## Безопасность
Не оставляйте пароль `change-me-now`. Для публичного сервера используйте HTTPS, reverse proxy и сильный пароль. Файл `data/state.json` содержит игровые данные и должен быть защищён от публичного доступа.


### Игроки и рейтинг
При первом запуске приложение регистрирует игрока на сервере по постоянному ID. Сервер хранит профиль, рейтинг и реферальную связь. Админ-панель получает этих игроков через `/api/admin/state`.

### Render и сохранение игроков
Для постоянного хранения `state.json` рекомендуется подключить Persistent Disk и задать переменную окружения `DATA_DIR=/data`. Без постоянного диска локальный файл может сбрасываться при пересоздании контейнера.
