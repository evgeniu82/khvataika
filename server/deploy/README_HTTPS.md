# HTTPS для «Хватайки» 2.0.0

Текущая игра использует `https://135.106.209.40` как production endpoint.

Для VDS без домена можно использовать публичный IP-сертификат Let's Encrypt. Такие сертификаты сейчас общедоступны, но короткоживущие (около 6 суток), поэтому в комплекте есть ежедневное автоматическое продление.

## Установка

```bash
cd server/deploy
EMAIL=you@example.com sudo -E ./setup_https_ip.sh
```

Скрипт:
- устанавливает Caddy + Certbot;
- получает IP-сертификат Let's Encrypt;
- оставляет Node API на `127.0.0.1:8080`;
- открывает наружу HTTPS через Caddy;
- включает ежедневную проверку/продление сертификата.

После установки:

```bash
curl -fsS https://135.106.209.40/health
```

В firewall публично нужны только TCP 80 и 443. Порт 8080 наружу лучше закрыть.

Если позже появится домен, достаточно заменить адрес в Caddyfile и `application/config/online_server_url` на `https://api.example.com`; доменная схема предпочтительнее IP-сертификата для долгосрочного production.
