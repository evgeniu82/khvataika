ХВАТАЙКА — АДМИН-ПАНЕЛЬ V3

Файлы:
public/admin-v3.html — новая адаптивная админ-панель.
public/index.html — перенаправление на admin-v3.html.

Важно:
- Серверные API не изменяются.
- data/ и .env не затрагиваются.
- Существующие данные игроков и игровая конфигурация не пересоздаются.
- Панель работает с существующими /api/admin/*.

Установка на сервер:
1. Сделать резервную копию текущих public/index.html и public/admin-v2.html.
2. Заменить public/index.html новым файлом.
3. Добавить public/admin-v3.html.
4. Перезапустить веб-сервис.
