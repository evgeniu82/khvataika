# Подпись Android / RuStore — Хватайка 1.13.6

Подпись приложения должна оставаться неизменной между обновлениями. В проекте **не хранится приватный keystore** и пароль от него — это сделано специально, чтобы ключ нельзя было случайно утечь через GitHub.

GitHub Actions уже использует постоянные секреты:
- `RUSTORE_KEYSTORE_B64` — постоянный release keystore;
- `RUSTORE_KEYSTORE_PASSWORD` — пароль;
- `RUSTORE_KEY_ALIAS` — alias ключа.

Для обновлений RuStore нужно продолжать использовать тот же keystore. Нельзя генерировать новый ключ для уже опубликованного приложения, если RuStore требует прежнюю подпись.

Сам ZIP исходников не может быть «подписан» как Android-приложение: подпись появляется у итогового APK/AAB во время export. Поэтому безопасный вариант — хранить release keystore только в GitHub Secrets и подписывать каждую сборку одним и тем же ключом.
